# 自建句子块视图，不使用现成阅读器渲染引擎

市面阅读器（foliate-js、epub.js、Readest 等）的核心是"忠实还原原书版式的分页渲染"，
而 LinguaLeaf 的核心交互是句子块流式对照阅读（原文行/音标行/译文行，三行一组），
渲染的是导入时生成的库内数据，从不渲染原始 EPUB 版式。因此不引入任何阅读器渲染引擎
（foliate-js 因依赖浏览器 DOM 在服务端导入管线中也没有落点），阅读 UI 用 React 直接渲染句子块。
若未来需要"原版式阅读模式"，再重估此决策。

## Considered Options

- foliate-js / epub.js：渲染引擎路线，与句子块 UI 冲突，且服务端不可用（DOM 依赖）
- 自建 React 句子块视图：数据模型简单（纯文本行），选中此路线
