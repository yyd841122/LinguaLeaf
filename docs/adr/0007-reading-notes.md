# 笔记独立于书签，以句子块或整书为落点

笔记保存读者手写的进度、感受、思路或疑问；书签仍只标记位置，标注仍是音标行和译文行。第一版在 web 章节阅读器中提供每块、每书各类型一条笔记，采用章与块的位置而非字符选区，避免引入尚不存在的字符身份与重定位协议。

笔记属于导入后的那本书，删除书时级联删除。重导入创建独立新书，不迁移笔记，原书及其笔记保留；内容寻址留待后续决策。类型是独立记录维度（进度、感受、思路、疑问），每个落点最多四条，各自保存和删除；进度类型不控制自动阅读进度。正文最多 10,000 字符、每书最多 100 条（含书级笔记）；满额仍可编辑。块级唯一键包含类型，书级空锚使用包含类型的部分唯一索引，防止 SQLite 的 NULL 唯一性语义允许多条书级笔记。

2026-11-05 修订：旧表的块级表内 UNIQUE 无法单独删除，开库时检查唯一索引，事务内重建并逐行保留旧数据；已含类型的新表不重建。块级浮层与书级展开区共用四分区编辑器，分区独立维护草稿、失败和保存状态。
