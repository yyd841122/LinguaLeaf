# 导出为自包含单文件 HTML（标注书文件），而非 EPUB/Markdown/PDF

v1 规格书曾把"导出标注版 EPUB/Markdown/PDF"列为 v2 规划。实际设计导出时确立了硬需求：
导出文件必须自带音标行/译文行的显示开关，且离线可用。静态 PDF 无法携带交互；EPUB 的开关
依赖阅读器执行 JS，主流阅读器默认禁用、无法保证；三者中只有自包含单文件 HTML 能同时满足
"开关随文件走、双击即用、断网可读"——浏览器即阅读器，不依赖任何安装。且本项目从不保留
原书版式（见 ADR-0001），导出内容本就是库内句子块数据的重新渲染，导出 HTML 与阅读页是
同一数据模型的两个前端。因此导出目标定为单一格式"标注书文件"（GLOSSARY.md），
EPUB/Markdown/PDF 导出暂缓；若未来确有需求（如打印），作为新增导出目标另议，不影响已有导出。

## Considered Options

- 静态 PDF：无法携带显示开关，违背离线开关硬需求
- EPUB：开关依赖阅读器 JS 支持，生态内无法保证
- Markdown：无交互载体，仅适合纯文本归档
- 自包含单文件 HTML：三项硬需求同时成立，选中
