# 06: 点词弹窗 + 发音

**What to build:** 阅读页点击原文中的任意词，弹出该词详情（音标、词性、中文释义，来自查词 API），详情内发音按钮用浏览器语音合成朗读该词，失败静默。弹窗可关闭，不打断阅读流。
