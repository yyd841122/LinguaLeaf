# 02: Markdown 导入到句子块阅读（第一条曳光弹）

**What to build:** 第一条打通全层的垂直切片：上传一个 Markdown 文件创建书，服务端抽取章节与段落、分句、生成句子块入库（音标行/译文行此票留空）；书架页能看到该书，阅读页按句子块渲染三行结构。Markdown 按标题层级划分章节，标题不生成句子块；代码块与链接不标注。

**Blocked by:** 01 项目骨架与双缝脚手架

**Status:** ready-for-agent

- [ ] POST /api/books 接受 .md 文件，创建书并可在 GET /api/books 看到
- [ ] GET /api/books/:id 返回目录（按标题划分的章节列表）
- [ ] GET /api/books/:id/chapters/:n 返回该章句子块数组（音标/译文为空）
- [ ] 阅读页按句子块渲染：每句一组三行，空行占位但结构完整
- [ ] 标题只作章节标题显示；代码块、链接原样显示、不进句子块
- [ ] API 缝测试：喂样例 .md，断言分句、目录与句子块结构
