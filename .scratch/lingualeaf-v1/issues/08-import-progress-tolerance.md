# 08: 容错与导入进度反馈

**What to build:** 导入过程可见、失败不吓人：导入时能以阶段或百分比看到进度，完成后书架状态更新；音标缺失与译文失败的句子按容错规则展示（该行留空或只显示可用行）；文件损坏等导入失败有明确提示且不留半成品书。

**Blocked by:** 03 ECDICT 音标行 + 查词 API；04 DeepSeek 译文行；07 EPUB 导入

**Status:** ready-for-agent

- [ ] 导入进行中可见进度（阶段或百分比），完成后书架状态更新为可读
- [ ] 音标查不到的词留空、译文失败的句子只显示可用行，阅读不被破坏
- [ ] 导入失败（损坏文件等）给出明确错误，不产生残缺的书
- [ ] API 缝测试：坏文件导入失败路径、假翻译器部分失败路径

## Comments

- 2026-10-17 (Claude): 票 04 评审转记:导入目前是单个同步 POST,翻译按批串行(roundtrip 最长 120s/批)——长书整本翻译可能把单请求拖进小时级,超出 ADR 0002"导入等几分钟"的成本包络,客户端/代理会超时。本票做进度反馈时应把导入改为异步任务(书架状态流转),顺带化解该风险。
