## 问题(triage 核实后修正,原票面写「web 两处」有漂移)

全仓 grep「原形」命中 9 处、横跨三个用户可见面:

- **web 弹卡** 1 处:`原形 {lemma}`(web 端暂无披露行;extension 已有「音标为词元 X 的读音。」)
- **导出注音副本弹卡脚本**(共享 reading-model 包内的导出文件脚本入口)1 处——
  它编译进一份**已提交的生成文件**(server 侧 `build:file-script` 产出),
  改脚本源后必须再生,否则 freshness 测试红
- **测试断言/注释 7 处**:web 两个组件测试文件 4 处 + server 导出测试 3 处

GLOSSARY「词元 (Lemma)」_Avoid_: 原形、词根、词族;CODING_STANDARDS
「User-facing copy speaks the glossary」:term just written down is the term
the UI renders。只改扩展不改其余两面 = 多前端文案分叉。

## 决策(维护者已锁,2026-10-30)

三面全改、**就地改字**,不抽共享文案常量(一词不建跨包 seam,与扩展侧修复
先例一致;review 勿再以「为何不抽常量」flag)。
