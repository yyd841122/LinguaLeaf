## High 发现(实现前必须解决)

1. **C1 实例归属**:`/api/health` 只回 `{"status":"ok"}`,不能凭 200 就复用——需核验归属(apps/server/src/app.ts:58)。
2. **C2 停止协议**:停止 = 核验 PID 归属 → 向真实 node 进程 SIGTERM → 等退出(覆盖 5 秒优雅窗口,main.ts:106)→ 超时报错;禁止按端口杀。
3. **F1 双击链环境**:wsl.exe 非交互 shell 不加载日常 PATH(nvm 等);需显式指定发行版/用户/仓库绝对路径/node 定位。
4. **F2 双侧可达**:WSL 内探针通过 ≠ Windows 浏览器可达;验收须从 Windows 实测。
5. **R1 同库双实例**:只按端口幂等会漏"同库不同端口"双实例;后启动者的中断任务清扫会把另一实例在跑的导入/翻译标失败(main.ts:26、task-lifecycle.ts:95)→ 启动互斥必须覆盖数据库身份。

## Medium/Low 要点

- 更新约定:重建不热替换已跑进程;.env 改动重启生效;复用时提示"正在用现有实例"(I1)

- 启动失败契约:早退/探针超时/库不可用/浏览器打不开的用户可见行为(C3)

2. 把端口/探针当进程身份 → 误复用/误停/漏杀
3. Windows→WSL 双击链未经实机验证
