# 01: 「重新翻译」一章端到端打通

**What to build:** 在任意一本已就绪的书里打开一章，工具栏第三个按钮显示「重新翻译」；点击后服务端起后台任务，按钮变为「翻译中 N%」禁用并以 1.5 秒轮询推进，完成后回到「重新翻译」，该章译文已刷新；同一章翻译进行中再点被 409 拒绝。这颗子弹打通所有层：章表新增翻译状态/错误/百分比列（存量章按"含句子块即已译"推导初值，译文数据零改动）、按章翻译触发路由（先过"书未就绪"守卫，同章进行中 409，否则 202 起后台任务——复用既有按章批量翻译：20 句一批、失败句重试三轮后留空）、章内容载荷增发翻译状态、阅读页按钮与轮询。部分句重试耗尽留空时章仍算已译，不加"未译出"提示。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 未就绪的书上触发翻译 → 409（并入既有"书未就绪"家族）
- [ ] 同章翻译进行中再触发 → 409；不同章并行合法（两章同时翻译中互不拒绝）
- [ ] 触发成功 → 202 + 章载荷；后台完成后章状态 translated 且载荷可见
- [ ] 单句三轮重试耗尽 → 译文留空、章仍 translated（「留空」语义在新路径重现，不删除）
- [ ] 章载荷带翻译状态；按钮三态变形 + 百分比轮询在阅读页可见
- [ ] 契约套件既有断言零删除零改写，新增只追加
- [ ] 每个实现 commit：typecheck && test && lint 绿（看退出码，不看 tail）；收尾 verify 全绿；基线 = 本票首个实现 commit 之前的 HEAD
