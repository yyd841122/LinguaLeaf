2. **进度 module**:新文件 `progressSession.ts`,接口
   `useProgressSession({ bookId, chapterNumber, ready })` → `{ saveFailed }`;
   module 自己按路由键 fetch(`readingProgress.ts` 的 helper 原地复用不搬);
   restore / 250ms 守卫 / 500ms debounce / flush / unavailable 停车 /
   saveFailed 全内聚;页面丢 `progress` + `"unavailable"` 两槽;`loadedRoute`
   留页面作 ready 派生机器(ready := content 已落且 loadedRoute 与路由匹配)。

   关在 ready,读者不可见)记 01 票 Comments。
3. **翻译触发 module**:`chapterTranslation.ts` 原地长成 trigger module

   onTick })` → `{ start, startFailed, pollFailed }`,内部包 useTaskFollower;
   202 走 onTranslationState(页面保持 merge)、tick 走 onTick(页面保持
   replace);startFailed 清零(落定 / tick / 路由变更)收进 module;
   `translateChapter` 转内部;类型再导出删除,reading.test.tsx 仅改一行类型
   import(见 Comments 和解记录)。
4. **测试只增不删**:两 module 各配 renderHook + 假计时器套件(形状循
   `taskFollower.test.tsx`:deferred / actAdvance);reading.test.tsx 原样跑绿
   即每票安全包络。瘦身另立后票(本 Comments 记档,不建 stub),凭 module
