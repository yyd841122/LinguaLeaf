# 手机端 UI 改版:暖纸沉浸阅读 + 微信读书式骨架
Status: confirmed(2026-11-16:三轮 grill → Codex 单轮评审 17 条 → 全量合并 → 维护者五题拍板「确定」→ 定稿,已拆 issues/ 11 票立项。P1 开工,Lane A)

## 一句话

手机端功能面既定,整体换装:阅读页做成参照图的暖纸极简风(无框沉浸 / 大边距 / 大行距 / 右缘红条),交互范式与外围骨架仿微信读书(点按呼出菜单 / 底部 tab / 封面书架),分三阶段十一票落地。

## 参照图事实

原图 `/mnt/e/笑来2026 AI 教程/阅读风格.jpg`(1118×1920)。出处维护者未提供,按像素分析为准(2026-11-16):

- 底色暖白纸 ≈ `#f6f5f1`(非纯白、非黄纸)
- 完全无框:无顶栏无底栏,上下各留 ~8% 空白
- 页边距左右各 **22%**(正文栏仅占屏宽 ~55%)
- 行距比 ~1.75,段落间再加大空行
- 全图近灰阶;唯一彩色 = 右缘 **6px 宽砖红竖条 `#c5322a`**,纵跨约两行
- 顶部:极小居中小字 + 左上小元素 + 一行通栏标题

## 现状事实(2026-11-16 现场取数;含评审轮补验 7 条,均逐一核对原文件)

- `apps/mobile` 单页状态机、无路由:ReaderLanding(书架 = 最近文档 + PDF 架 + 虚线导入区 + 备份块)→ EpubReader(`EpubReader.tsx` 1080 行)/ PdfReader(+ 重排)+ overlays
- EpubReader 头部常驻三行:书名 / 听书控制条 / `reader-tools` 工具行(`EpubReader.tsx:709`,**8 钮**:音标、译文、翻译(标签带 % 态)、设置、目录、书签、置底|置顶(`:781`)、返回);footer pager 上一章(`:1064`)/ 下一章(`:1074`);**无点按分区**
- **PDF 原版工具行同样常驻,含音标开关**(`PdfReader.tsx:161` 起,`aria-pressed={showIpa}`)——「PDF 原版无音标」是错的
- 阅读进度与书签落点**共用 `.reader-head` 底边作锚**(`EpubReader.tsx:72`,找不到时兜底 96px)——撤常驻头 = 锚点契约必须迁移
- 样式:纯 CSS;`reader.css` 988 行,`:root` **17 个颜色 token**(`:11-28`,`--accent: #6a4fa3` 音标紫),`--reader-max: 44rem`(`:31`);暗色 = `@media (prefers-color-scheme: dark)`(`:862`)整段重映射,无手动切换
- `ui-settings-store.ts` 现只存一项:`pdfToolbar: top|bottom`(version 1 记录)
- 音标开关是 ReaderPage 内全局 React 状态、译文开关是 EpubReader 内临时状态——**两者今天均无逐书持久化**
- kernel 共享表 `packages/reading-model/src/annotated-shared.css`:`--original-size` 兜底 1.15rem(`:23`)、`line-height: 2` 预留标注带(`:26`,绝对定位音标行);`EpubChapter.tsx:137` 消费 kernel `AnnotatedBlockView`
- 库存 = 解析后 `ExtBook`(`library-store.ts` `saveDocument({id,title,book})`),**不保留原始 ZIP/OPF/封面字节**——存量书原封面物理上无法从库内恢复
- 词汇记录 = **词元→状态** 二元组(`vocabulary-store.ts` StateBackend),无来源书 / 位置信息;`exportAll` 只返回三个已存态,New = 记录缺失
- 导入把每个 spine 文档按标题拆成多章、跳过空文档(`import-core/src/epub.ts:185` 起),`ExtBook` 只存章节——**spine 身份已丢,spine 百分比不可得**
- 文档身份 = `doc:${title}`(`backup.ts:31` `docIdFromTitle`,docId↔title 是跨端 join 键)——直接改 title 会使笔记/书签/译文/进度失联
- PDF 架元数据 = `{docId, title, size, storedAt}`(`idb-bytes-store.ts`),**无总页数、无逐书最近打开时间**(storedAt 是保存时间)
- 导入链无 EPUB 封面抽取(import-core 全量 grep,"cover" 仅见于注释 `extract-html.ts:169`、`epub.ts:55`)
- 手机端无独立生词本页:生词只出现在查词弹窗四态钮与书架备份统计行(`ReaderLanding.tsx:166`)
- 无排版设置入口:字号 / 边距 / 行距均不可调(apps/mobile 全量 grep 无命中)
- `apps/mobile/test/touchPolish.test.ts` 钉死 44px 触控底线与命中区扩规则
- 在队票:`mobile-app` 08 听书后台 **ready-for-agent**;11 / 12 / 13 **needs-triage**;06 touch polish 已 done

## 已拍板决策

### 第一轮:意图与边界(grill,维护者「全按推荐」)

1. 仿微信读书三层全取:**导航骨架**(底部 tab + 书架,内容按 LinguaLeaf 自映射)、**阅读交互范式**(菜单默认隐藏、点中央呼出)、**视觉气质**;书城 / 想法等不造
2. 边界:**只手机端**;EPUB 阅读页 + 书架 + PDF + 各弹窗全部进本期;web 与扩展不动;kernel 共享 CSS 继续走 **app 侧覆盖隔离**(06 票先例)
3. 节奏:三阶段,每阶段独立可验收、真机机检过关再进下一段
4. 参照图**五特征全要**(暖纸底 / 无框沉浸 / 22% 大边距 / 1.75 大行距 / 右缘红竖条);红条 = **句级学习标注**;边距照图做默认 + 三档可调
5. 阅读页范式:菜单默认隐藏、点中央呼出、点两侧翻章;**保持竖向连续滚动,不换分页**(→ ADR-0009)
6. 主题:手动四档 **暖纸 | 白 | 夜间 | 跟随系统**,暖纸默认;对 06 票「仅跟随系统」的有意扩展
7. 底部三 tab:**书架(含导入)/ 生词本 / 我**;轻量 tab 状态、不引路由库;生词本页为新增页
8. 纪律:批次 `.scratch/mobile-ui-redesign/`;每票测试同步全绿;阶段出口真机机检(device-check);Lane A(Claude 直做)

### 第二轮:设计细则(grill,维护者「全按推荐」)

1. **标注层**:信息架构不变(音标行内对 / 译文整行 / 笔钮保留),视觉降噪——音标 ~0.72× + 暖灰、译文 muted;音标 + 译文全关时行距回落 1.75 纯文字;章首版式仿图(居中序号小字 + 通栏标题)
2. **呼出菜单**:顶栏 = ← 返回 | 书名·章节名 | 进度;底栏 = 目录 / 书签 / 音标 / 译文 / 翻译 / 听书 / Aa;听书二级面板(播放 / 句步进 / 倍速);Aa 面板装排版与主题;目录面板 = 章节列表 + 进度滑杆;撤常驻三行头、footer pager、置顶 / 置底
3. **红条**:P1 纯指示不可点;收编替代书签左 ribbon,全 app 只一种页缘标记
4. **档位**:字号 5 档(1.0/1.15/1.3/1.45/1.6rem)、边距 3 档(12%/17%/22%,默认宽)、行距 3 档(1.5/1.75/2.0,默认 1.75);字体族不换;档位全局统一存 ui-settings~~,per-book 只保留音标 / 译文两个学习开关~~(→ 第四轮 2a:逐书开关是**新增**能力)
5. **配色**:accent 紫 `#6a4fa3` → 砖红 `#c5322a`;音标紫退役改暖灰;四态绿系保留;夜间砖红提亮
6. **书架**:3 列封面卡,卡下书名 + 进度%;最近在读横滑 + 全部网格;EPUB / PDF 混排一架;长按 = 改名 / 删除;右上 + 导入;备份块迁「我」页~~存量书回填原封面~~(→ 第四轮 8a:不可行,改兜底 + 重导补齐)
7. **生词本页**:列表 + 四态筛选 + 点词回弹窗;复习模式不做~~来源书名~~(→ 第四轮 9b:砍字段)
8. **我页**:设置 + 备份恢复 + 统计(store 现算不加埋点);一屏放完
9. **PDF 面**:外壳统一新范式;~~原版 canvas 纸面不套暖纸~~(保留);重排全主题化;~~菜单同构减法(原版无音标 / 译文…)~~(→ 第四轮 1:原版**有**音标,减法修正)

### 第四轮:Codex 单轮评审合并(2026-11-16,gpt-6.1-sol · high · read-only)

评审 thread `01a1e4d0-b9df-7e71-b5fd-a04d972e8f47`,verdict **NEEDS REVISION**,17 条发现(High 9);承重论断抽验 **7/7 属实**。修订全文如下,与维护者五题拍板(「确定」)一并生效:

**Hard fact 修订(物理不可行 / 现状写错)**

- **1. PDF 原版有音标开关**(`PdfReader.tsx:161` 已核):菜单同构减法修正——PDF 菜单**保留音标**(原版 + 重排),减**译文**(EPUB 专属),增 zoom 阶梯与重排 / 原版切换
- **2. 逐书音标 / 译文开关是新增能力**(今天无逐书持久化):拍板 **2a** = 新增逐书键,归 02 票,默认值 = 现全局值迁移;换书 / 冷启 / 返回书架行为在票内定义
- **3. ADR-0009 翻章约束限定 EPUB / MD**:PDF 原版与重排的边缘点按仍按**物理页**导航——两套导航契约并存有意为之(页本就是 PDF 的自然阅读单元)
- **8. 存量 EPUB 封面不可自动回填**(库无原始字节):拍板 **8a** = 新导入抽取入库;存量书先兜底封面,重新导入原书时按内容指纹补齐;不承诺首开自动恢复
- **9. 生词本来源书名无数据来源**(词汇 = 词元→状态):拍板 **9b** = P2 砍掉该字段;来源记录立后续票
- **10. spine 百分比不可得**(拆章后 spine 身份即丢):进度滑杆改称并实现为**章节进度**(章节索引百分比);Markdown 同义

**契约补全**

- **5. 书架改名 / 删除 = 新增存储能力**:改名走**显示名层(displayName)叠加稳定 docId**(`doc:${title}` 身份与备份 join 不动);删除按 GLOSSARY 书架语义保留学习资产;重名与写入失败处理入 06 票
- **6. 阅读锚点契约迁移**:进度与书签落点锚**独立于呼出菜单几何**(现 `.reader-head` 底边 / 96px 兜废);验收 = 菜单开关不改书签落点、排版变化后重开位置正确、笔记未保存拦截与听书进度所有权保留
- **7. 封面缓存生命周期**:有界、按可见项调度、先兜底、按内容身份失效、删除期间晚到结果不回写、PDF worker / 对象 URL 清理
- **11. 排版档位与音标开启态**:档位作用于**纯文字行**;音标开启时定义**最小有效行距**(kernel 双倍行高预留 vs 1.5 档 / 0.72× 音标的相撞处理);验收 = 字号 × 边距 × 行距 × 两开关**全组合矩阵**(含长音标、窄屏)
- **12. 生词本 New 无集合**:chips = 全部 / 学习中 / 已掌握 / 已忽略,**New 不单列**(拍板 **d**);列表词典信息走**只读接口**,渲染不得触发 `store.lookup()` 副作用——点词查详情才自动登记 New→学习中
- **13. 点按优先级与热区几何**:词 / 笔钮 / 弹窗 > 菜单背景点(菜单只响应非交互背景点按);边缘热区宽 = **实际边距档**(非固定 22%);定义拖动 / 长按取消 / 选择文字期间 / 章首章末行为
- **14. 红条真值表**(拍板 **c**):触发 = 句中含**学习中**词元即显(已掌握 / 已忽略不显,New 无记录不显);状态跨书通用(学习者资产);红条贴**正文栏右缘**、随边距档移动;PDF 原版按**行**、重排按**句**定位
- **15. 统计口径**:在读书 = 有进度未读完;生词总数 = 已存词汇记录数;笔记总数 = EPUB 块笔记 + 书级 + PDF 行笔记(pdf-notes 补只读统计接口);进度% = 已完成块 / 总块(EPUB)、已读页 / 总页(PDF);未知数据展示「—」;PDF 架补总页数与逐书最近打开时间元数据
- **16. P1 切票重排**(拍板 **e**):原 02(无框化)+ 03(排版)**合并**为一票,PDF 范围与验收矩阵写进合并票;移除旧入口前先在新结构上验证最小真实阅读面(出口票验收)
