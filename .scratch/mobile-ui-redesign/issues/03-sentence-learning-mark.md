## 目标

参照图右缘砖红竖条落地为「句级学习标注」(GLOSSARY),并收编现有书签左 ribbon。

## 范围

- 真值表(拍板 c):句中含**学习中**词元即显;已掌握 / 已忽略不显;New(无记录)不显;状态跨书通用(学习者资产)
- 触发源:学习中词元 / 笔记 / 书签任一存在即显,共存只显一条
- 几何:贴**正文栏右缘**、随边距档移动;高度 = 句子块(EPUB)/**行**(PDF 原版)/**句**(PDF 重排)
- 收编替代书签左 ribbon(`.block-marked::after` clip-path),全 app 只剩一种页缘标记;纯指示不可点
- 色:砖红(01 令牌),夜间取提亮值

## 验收门

- 状态流转即视觉同步:学习中 → 已掌握,红条消失;反向恢复
- 三类触发源各自单独成立;共存单条
- PDF 原版按行、重排按句定位正确
- ribbon 旧样式与其测试清除;EPUB 与 PDF 两面一致
