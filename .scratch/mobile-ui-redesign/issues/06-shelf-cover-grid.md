# 06 书架封面网格
Status: ready-for-agent(2026-11-16 立项;spec v2)
Blocked by: 05

## 目标

微信读书式封面书架;新增封面资产链与显示名层。

## 范围

**封面资产链(评审 8 条,拍板 8a)**
- **新导入**:EPUB 抽取 OPF 内嵌封面入库;PDF 首页 pdfjs 渲染缩略;MD 无封面直接兜底
- **存量书不回填原封面**(库只存解析后 ExtBook,物理不可行):先显示兜底封面(纯色底 + 书名首字),重新导入原书时按内容指纹补齐真封面
- 缓存生命周期契约(评审 7 条):有界、按可见项调度、先兜底后替换、按内容身份失效、删除期间晚到结果不回写、PDF worker / 对象 URL 清理

**书架形态**
- 3 列封面卡:封面 + 书名 + 进度%;顶部「最近在读」横滑行 + 「全部」网格;EPUB / PDF / **MD 混排一架**(MD 明确入架)
- 最近在读:补**逐书最近打开时间**元数据(EPUB 用 recents 现成;PDF 架现只有 storedAt 保存时间);PDF 架补**总页数**元数据(打开时记录,供 08 统计)
- 长按卡片 = 改名 / 删除
- 导入 = 右上 + 按钮;虚线拖放区退役

**改名 / 删除语义(评审 5 条)**
- 改名 = **显示名层(displayName)叠加稳定 docId**;`doc:${title}` 身份与备份 join(`backup.ts` `titleFromDocId`)不动
- 删除按 GLOSSARY 书架语义:移除本地原书副本,**保留**笔记 / 书签 / 译文 / 阅读进度
- 重名(显示名相同)可共存;写入失败有界降级(显示旧值)

## 验收门

- 无空槽:任何书都有封面或兜底
- 新导入带真封面;存量书先兜底、重导原书后补齐(走通一次)
- **改名后**:笔记 / 书签 / 译文 / 阅读进度 / 备份 join 全不断(端到端测)
- 删除后学习资产保留;重导同名书资产回挂
- 元数据:最近打开时间排序正确;总页数入档
